# 个性化分析助手源码快照

这是从现有应用目录提取的当前源码及可得的部分文件备份，不是完整 Git 提交历史。

## 运行

在仓库根目录执行：

```sh
Rscript 安装R依赖.R
Rscript serve.R --port 19980
```

R 依赖以 `安装R依赖.R` 为准，实际所需的系统工具、Python 包、分析工具链及外部服务需按使用功能另行配置。可参考 `使用说明.txt` 和启动脚本；这些保留的历史说明不等于本次验收结论。

## 运行配置与数据边界

运行 `config/` 不收录。部署前须自行设置适合目标环境的配置及凭据，不应把真实凭据加入版本控制。

不收录运行状态、数据库、日志、结果、用户科研数据、归属批准记录、agent_tokens、server_profile 或缓存。源码中对这些路径的引用属于程序接口，不代表对应运行记录随仓库提供。运行时按程序需要在本地创建目录和配置。

## 可得旧文件

`public/` 中带版本号的 JavaScript/CSS 是历史静态代码文件，保留原路径。

原目录中 `*.bak*` 源码或静态源码配置备份移到 `history/source-backups/<原相对路径>`，没有伪造历史日期的 Git 提交。这些仅为部分文件历史，不是完整、可独立运行或已验收的历史版本。原目录无 `.git`，无法从这些文件恢复完整提交历史。

## 验证范围与风险

本次只准备本地暂存快照，执行文件筛选、敏感模式扫描、逐文件 SHA-256 及 HTML 本地静态资源引用检查；没有启动服务或运行完整分析流程，没有声称全部功能已验收。

敏感模式扫描是启发式检查，不等同于无敏感信息保证；测试中的合成安全样例、内网地址、示例账户、个人路径及文档元数据仍需人工复核。扫描报告留在仓库之外，以文件名、行号、类别记录，不包含命中的值。

代码库内嵌的分析脚本与 PPT 模板的来源、授权和可再分发范围需要维护者确认；本快照不新增许可证，也不主张第三方材料所有权。科学数据未纳入。
