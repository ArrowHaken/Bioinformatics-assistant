# 个性化分析助手 · 整包

拷到目标电脑上就能用。有 R 就能开，不用装 Node。

---

## 一、电脑上要先有的东西

1. **R**（4.2 以上，建议 4.3+）
   https://cran.r-project.org/bin/windows/base/

2. **R 包** —— 这是最关键一步，缺了会跑到一半停住。
   双击本包里的 `安装R依赖.R`，它会依次装齐。
   约 20~40 分钟，看网速。

3. **Python 3** —— 只有「出 PPT」这一步用。不装也能跑前面几步。

4. **内存**建议 16GB 起。8GB 能跑，大样本会走分块路径（结果等价，慢一些）。

---

## 二、怎么用

1. 整个文件夹拷到目标电脑，**路径里不要有中文**，例如 `D:\sc_assistant\`

2. 双击 `启动助手-双击这个.bat`
   - 弹出黑色窗口（那就是服务，别关）
   - 浏览器自动打开 `http://127.0.0.1:18980/`

3. 网页上按顺序做：

   ① 选运行目录（空文件夹就行）
   ② 点「生成一份默认设置」
   ③ 答完 **「现在就要定」** 那一组（4 件）
      数据目录 / 注释依据 / 质控门槛 / 读入前剔样本
   ④ 点「保存我的设置」
   ⑤ 点「一键全流程」，或一步步点
   ⑥ 跑到 **「跑主流程 · 上段」** 结束时会自动停住
      这时页面上的 **「有数据了再定」** 那一组会自己填上实测依据：
      - 每个簇多少细胞、占多少
      - 每个簇在各个样本里各有多少（看它是不是某个样本特有）
      - 每个簇靠哪些基因聚在一起（看它大概是什么细胞）
      - 每个样本多少细胞（看剔样本会不会把某组削平）
   ⑦ 看着这些数字做选择，保存，然后点 **「跑主流程 · 下段」**
   ⑧ 继续出图 → 出 PPT → 打包

4. 结果在「产物下载」里，也可以直接下那个 zip。

**要停止服务**：关掉黑色窗口。
**分析结果不会丢**，都在运行目录的 `results/` 里。

---

## 三、为什么要分两步答问题

因为这两类决定的**依据来源不同**：

- **现在就要定的**（数据在哪、质控门槛等）
  不看数据也能定，不定就跑不起来。

- **有数据了再定的**（剔除哪些簇、剔哪个样本、低置信门槛）
  判断依据只有**跑到一次聚类**才会算出来。
  提前问，等于让你在没有材料的情况下猜 —— 那和脚本瞎猜一样糟。

所以流程是：**跑到那里 → 算出依据 → 停 → 你定 → 接着跑**。

编辑 `启动助手-双击这个.bat`，改最上面那行：

    set "RSCRIPT=D:\soft\R412\bin\Rscript.exe"

或先设环境变量再双击：

    set RSCRIPT_PATH=D:\soft\R412\bin\Rscript.exe

## 六、几条硬规则（不是建议）

1. **底层脚本拒绝被直接调用。**
   直接 `Rscript 01_preprocess.R` 会当场停住并说明原因。
   必须经 `engine/sc_workflow.R` 跑，否则参数来源、台账、产物指纹都留不下来。

2. **入口守卫被改或被删，所有运行都会停。**
   防的是「把检查删掉」这种绕过方式 —— 包括我自己去删。
   改了就停，并写进台账，藏不住。

3. **每一步都写进只追加的台账。**
   什么时间跑的、用了哪些参数、退出码、产物指纹。
   `verify` 可以事后核对产物还在不在、有没有被改。

4. **参数没定下来就不跑。**
   带着猜的值算完，不会报错，只会算出一份看起来正常、但错的结果。

## 七、常见问题

**浏览器打不开页面**
黑色窗口里会打印失败原因。多半是 18980 被占了。
命令行里跑 `Rscript serve.R --port 18981`，浏览器开 18981。

**提示「跑主流程之前要定 N 件事」**
这是设计，不是故障。去「现在就要定」那组答完、保存，再运行。

**跑完上段就停了**
对，应该停。去「有数据了再定」那组看依据、做完选择，再跑下段。

**提示「机器上已有现成脚本」**
这台电脑上已经有分析脚本了。先确认用哪套 ——
两套并行跑同样的数据早晚分叉，到时会说不清哪个结果算数。

**跑到一半停了**
看「运行日志」。失败原因写得很明确，而且停在那里不往下走。
修好后**单点出问题的那一步**继续，不用从头来。

**内存不够**
体检会直接告诉你。不够时自动走分块路径，不抽样、不降精度，
结果与直接算一致（已实测）。

**能不能只把网页发给别人？**
不行。网页只是界面，干活的是背后的 R 脚本，必须在同一台机器上。
要拷就拷整个包。
