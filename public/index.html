      执行快照与清单 notebook：独立重放说明
      
执行快照不等于独立重放。执行快照记录本次执行信息；“打包清单 notebook”按明确授权的 manifest 嵌入文件，不会自动发现依赖，也不代表完整分析已验证。

      
要用单个 notebook 独立重放，files 必须列全所有直接、间接依赖的脚本（script）、配置（config）和输入（input）；每个 input 必须显式填写 embed_authorized: true。steps 按执行顺序填写 command、argv 和 cwd；command 只支持 Rscript、python 或 python3，argv 第一项必须是已声明的脚本。expected_outputs 填写同次成功执行已经存在的输出，打包时记录其字节数和 SHA-256 作为重放比对基线；打包本身不执行分析。

      
所有文件路径相对本次分析 run_dir；cwd 可为“.”。不允许绝对路径、路径穿越（..）、符号链接（symlink）或敏感凭据；脚本、配置必须为 UTF-8。默认单文件上限 10 MiB（10,485,760 bytes），嵌入文件合计上限 50 MiB（52,428,800 bytes）。

      
实际重放需配置 Python 3 内核，以及所需 R/Python 解释器和依赖包；环境和外部服务不会被完整冻结。重放不是沙箱，不要运行不信任代码。

      
下面是可复制的 manifest JSON。示例文件名不代表实际目录，需按实际分析填写；out.csv 必须已由同次成功执行生成，不能用示例代替真实输出基线。

      
{
  "files": [
    {"path": "main.py", "role": "script"},
    {"path": "input.csv", "role": "input", "embed_authorized": true},
    {"path": "settings.json", "role": "config"}
  ],
  "steps": [
    {"title": "运行分析", "command": "python3", "argv": ["main.py"], "cwd": "."}
  ],
  "expected_outputs": ["out.csv"]
}

      
页面“选择重放清单”上传的 JSON 只用于本次手动打包，不会保存为自动清单。自动打包仅本地执行可用：将明确授权的清单保存一次到 run_dir/replay-manifest.json 后，只有所有 phase 成功且绑定真实 session 的执行完成后才尝试自动打包；没有该文件就跳过，不自动发现文件。
